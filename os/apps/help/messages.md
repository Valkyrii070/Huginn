# Messages
Chat with friends over Matrix, an open network: they can use any Matrix app on any server.

## Sign in
Type your Matrix address (like @name:matrix.org), your password and your vault's master password. "Make an account" opens Element's sign-up page if you don't have one yet.

## Start a chat
New Chat asks for a friend's Matrix address. The chat is end-to-end encrypted, and they're asked to join.

## Send a file
The plus button beside the message box sends a file. In an encrypted chat the file is encrypted too.

## Invitations
Someone asking you to a chat shows at the start of the row of faces, with Join and No.

## Notifications
New messages show a notice with only who it's from. "Show the words of a new message" in Account turns on the text. "Keep getting messages after the window closes" keeps Messages listening.

## A message says it can't be read
It was encrypted for your other devices before this one signed in. Ask the sender to send it again.
