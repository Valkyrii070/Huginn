# Authenticator
Two-factor codes for your accounts, kept in your vault.

## Add a code
When a website shows a QR code for an "authenticator app", press Add a Code and choose "Scan the screen" while the code is visible, then Choose the Area. You can also copy the set-up link (it starts with otpauth://) or a picture of the QR code and press Paste, drop a picture onto the window, or choose "Type a key" for the key the website writes out.

## Use a code
Click a dial to copy its code. The ring shows how long the code has left.

## Move codes from your phone
In Google Authenticator, choose Transfer accounts, then Export accounts, and take a picture or screenshot of the QR code it shows. Paste or drop it here: every code in it comes across.

## Codes in Passwords
The code for a site also shows on its login in Passwords.

## Keep a way back in
Codes live in your vault, so Backup keeps them too. Losing your master password means losing them, so keep each site's backup codes somewhere safe.
