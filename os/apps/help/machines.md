# Machines
Try other operating systems in a window: Linux, Windows and others, safely apart from your own.

## Making a machine
Download an installer (an .iso file) into Downloads, then press New Machine (Ctrl+N). Machines recognises Ubuntu, Fedora, Debian, Mint, Windows and others, and suggests memory, processors and a disk size to match; change them if you like. The disk only takes up space as it fills.

## Starting it
Make It and Start: the machine's screen appears in the window and the installer starts from the disc. Click inside the screen to type into it; the keys go to the machine until you click outside it. When it's installed, press It's Installed to take the disc out, so it starts from its own disk.

## Windows 11
Machines gives Windows machines what Windows 11 asks for: UEFI with Secure Boot and a TPM.

## Ctrl+Alt+Delete
The keyboard button sends Ctrl+Alt+Delete, which your own computer would otherwise catch first.

## Snapshots
A snapshot keeps the machine exactly as it is, running programs included. Take one before trying something risky, and go back to it if things go wrong.

## Pause, shut down, carry on
Pause freezes the machine and Carry On wakes it; Shut Down asks it to shut down properly; Turn Off Without Asking is pulling the plug. If you close Machines while a machine is running, it's saved as it is and carries on where it left off next time.

## Sharing a folder
In a machine's Settings, share a folder of yours (Public, to start with). Inside a Linux machine it can be mounted as "hostshare". The machine reaches the internet through your computer, and nothing on the network can reach it.

## Speed
On computers with hardware virtualization (KVM), machines run close to full speed. Without it they still work, slowly.
