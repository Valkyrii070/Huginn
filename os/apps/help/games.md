# Games
All your games in one place: Steam, Epic, GOG, Amazon and your own.

## Where games come from
Games you install with Steam appear by themselves, Windows games included. Epic, GOG and Amazon games appear once they're installed with Heroic, a free launcher for those three shops (you sign in to those accounts inside Heroic).

## Add your own
Press Add a Game and pick the game's program (a Windows .exe or a Linux game), or drop it onto the window. Each Windows game gets its own bottle for saves and settings.

## Play
Pick a game in the carousel and press Play. Stop ends it.

## A profile per game
Choose the compatibility layer, launch arguments, environment variables, the performance overlay, GameMode and which copy of a Windows file wins.

## Take Off the Shelf
Removes a game from this list only. Its files and saves stay.
